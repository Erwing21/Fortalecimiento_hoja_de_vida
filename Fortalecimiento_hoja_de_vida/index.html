Fortalece tu hoja de vida

Consejos, estructura y ejemplos para construir un CV que destaque.

Consejos clave

Marca cada consejo a medida que lo apliques en tu hoja de vida.

Progreso: 0 de 6 consejos aplicados

Evita apodos o numeros aleatorios. Usa una combinacion de tu nombre y apellido.

Un resumen de 2 a 3 lineas sobre quien eres y que buscas profesionalmente.

En vez de "apoye en un proyecto", escribe "reduje el tiempo de entrega en un 20%".

Empieza por lo mas reciente. Incluye practicas, proyectos y trabajos por horas.

Revisa dos veces el texto y manten un mismo estilo de letra y tamaño en todo el documento.

Resalta las habilidades y experiencias mas relevantes para el puesto al que aplicas.

Estructura de una hoja de vida

Estas son las secciones recomendadas que debe incluir tu CV como estudiante.

1. Datos personales
Nombre completo, ciudad, correo profesional, telefono y enlaces (LinkedIn, portafolio).
2. Perfil profesional
Resumen breve de tu formacion, intereses y objetivo profesional.
3. Formacion academica
Programa que estudias, institucion, semestre actual y fecha estimada de grado.
4. Experiencia
Practicas, proyectos de clase relevantes, trabajos de medio tiempo o voluntariados.
5. Habilidades tecnicas
Lenguajes de programacion, herramientas, software y tecnologias que manejas.
6. Idiomas
Idioma y nivel aproximado (basico, intermedio, avanzado).
7. Referencias (opcional)
Nombre y contacto de un profesor, jefe o mentor que pueda dar referencias.

Ejemplos de perfiles

Ejemplos breves de como redactar el perfil profesional según tu situación.

"Estudiante de Tecnologia en Desarrollo de Software, quinto semestre. Interesado en programación web y con proyectos personales en HTML, CSS y JavaScript. Busco una práctica para aplicar mis conocimientos."

"Estudiante de septimo semestre con experiencia en proyectos de aula usando Java y bases de datos relacionales. Participé en el desarrollo de un sistema de reservas como proyecto de curso."

"Estudiante de ultimo semestre con seis meses de practica en soporte tecnico y desarrollo web básico. Manejo de HTML5, CSS3 y control de versiones con Git."
