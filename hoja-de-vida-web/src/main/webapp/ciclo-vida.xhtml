Arquitectura: de qué se encarga cada pieza

Navegador → FacesServlet → Componentes (Facelets) → Bean CDI → Respuesta HTML.

PiezaFunción en esta página
NavegadorEnvía la solicitud (GET al abrir, POST al pulsar el botón).
FacesServletDeclarado en web.xml con el patrón *.xhtml; recibe la solicitud y ejecuta el ciclo de vida.
Componentesciclo-vida.xhtml define el árbol de componentes (formulario, campos, botón, mensajes).
Bean CDIPerfilCicloBean (@Named, @ViewScoped) guarda los datos y ejecuta guardar().
RespuestaEn la fase 6 se dibuja el HTML con los valores, mensajes y contador actualizados.

Las seis fases del ciclo de vida

FaseQué sucedeGET inicialPOST válidoPOST inválido
1. Restore ViewSe crea o restaura el árbol de componentes.SíSíSí
2. Apply Request ValuesCada componente toma el valor enviado.NoSíSí
3. Process ValidationsSe revisan required y f:validateLength.NoSí (correcta)Sí (falla)
4. Update Model ValuesLos valores se copian al bean.NoSíNo
5. Invoke ApplicationSe ejecuta guardar().NoSíNo
6. Render ResponseSe dibuja el HTML de respuesta.SíSíSí

Con un error de validación, JSF salta de la fase 3 directamente a la fase 6: el bean no se modifica y la acción no se ejecuta.
